# Demo Guide

1. Start backend and frontend.
2. Set `LLM_PROVIDER=mock` for a no-key plumbing demonstration or configure OpenRouter for live LLM inference.
3. Index `backend/data/playbook/legal_playbook.md`.
4. Upload `sample_data/Sample_High_Risk_MSA.txt`.
5. Review liability, IP, confidentiality and indemnification findings.
6. Show the combined liability/indemnification exception flag.
7. Explain that mock mode is heuristic and not genuine AI assessment.
8. For a live demo, use OpenRouter with a currently available model and verify the provider connection first.
